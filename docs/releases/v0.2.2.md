# dsh-keysmith v0.2.2

This release preserves the bundle fields in the composed `system-prompt` row,
including `personaPrefix` and `personaSuffix`, when generating the home patch.

Config composition is skipped for missing or incomplete `profiles/web` directories.
An incomplete profile produces a warning and falls back to the base patch without
invoking dsh or creating profile files. Preview never invokes dsh.

The JSON contract remains `dsh-keysmith/v1`. The adapter hot-fix is still skipped
with a warning when its target is absent or does not match a known source snippet.

Assets: standalone Python CLI, source ZIP, source tar.gz, and `SHA256SUMS`.
Verify the checksums before using the downloaded CLI. No runtime dependencies
beyond Python are required.
